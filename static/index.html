CLI Usage

                    

# Analyze package
python main.py package.deb

# Generate default.nix
python main.py package.deb --output-dir ./mypackage

# Universal analyzer
python universal_analyze.py package.AppImage

# Start web server
python server.py

# With URL
python main.py --url https://example.com/package.deb

                                Suivez ces etapes pour convertir un paquet Linux en derivation Nix compatible NixOS.
                            


                            

                                1
                                

                                    
Choissisez votre paquet

                                    

                                        Deposez un fichier (.deb, .AppImage, .rpm, .tar.gz, .flatpak, .snap)
                                        dans la zone de depot ou cliquez pour le selectionner.
                                        Vous pouvez aussi fournir une URL de telechargement direct.
                                    

                                

                            


                            

                                2
                                

                                    
Connectez-vous a l'API

                                    

                                        Entrez l'URL de l'API (par defaut http://localhost:8000)
                                        et cliquez sur Connect.
                                        L'URL est sauvegardee automatiquement.
                                    

                                

                            


                            

                                3
                                

                                    
Lancez la conversion

                                    

                                        Cliquez sur Convert.
                                        La progression s'affiche etape par etape avec le temps ecoule
                                        et les logs en direct dans le terminal integre.
                                    

                                

                            


                            

                                4
                                

                                    
Recuperez le resultat

                                    

                                        Trois onglets sont disponibles :
                                        Nix Expression (copier ou telecharger),
                                        Install Guide (instructions detaillees),
                                        Auto Script (script d'installation automatique).
                                    

                                

                            


                            

                                5
                                

                                    
Installez sur NixOS

                                    

                                        Copiez la commande d'installation, telechargez le script,
                                        ou suivez le guide pas a pas.
                                        Les variables NIXPKGS_ALLOW_UNFREE et
                                        NIXPKGS_ALLOW_UNSUPPORTED_SYSTEM sont
                                        automatiquement configurees.
                                    

                                

                            

                        


                        
                        

                            

                                
                                app2nix supporte les formats de paquets Linux suivants.
                            


                            

                                
.deb Paquets Debian/Ubuntu

                                

                                    Analyse approfondie : extraction du fichier DEBIAN/control,
                                    detection des binaires ELF via ldd et patchelf,
                                    mapping des dependances vers Nixpkgs.
                                

                            


                            

                                
.AppImage Applications portables

                                

                                    Extraction via --appimage-extract, analyse des bibliotheques
                                    dans squashfs-root/ avec patchelf --print-needed.
                                

                            


                            

                                
.rpm Paquets Fedora/RHEL

                                

                                    L'analyse RPM extrait les metadonnees de base. Le binaire est copie
                                    directement et autoPatchelfHook s'occupe des dependances.
                                

                            


                            

                                
.flatpak Applications Flatpak

                                

                                    Les paquets Flatpak sont extraits et integres avec
                                    autoPatchelfHook pour la resolution des dependances.
                                

                            


                            

                                
.snap Paquets Snap

                                

                                    Les paquets Snap sont supportes avec extraction de base et
                                    correction automatique des ELF.
                                

                            


                            

                                
.tar.gz Archives

                                

                                    Les archives .tar.gz et .tgz sont supportees.
                                    Le contenu est extrait et les binaires sont patche automatiquement.
                                

                            

                        


                        
                        

                            

                                
 Qu'est-ce qu'une derivation Nix ?

                                

                                    Une derivation Nix est un ensemble d'instructions de construction
                                    declarees dans le langage Nix. Elle decrit comment telecharger,
                                    compiler et installer un logiciel de maniere reproducible.
                                    app2nix genere ces instructions automatiquement.
                                

                            


                            

                                
 Puis-je utiliser ceci sans NixOS ?

                                

                                    Oui. Vous pouvez installer Nix sur n'importe quelle distribution
                                    Linux (Ubuntu, Fedora, etc.) avec la commande
                                    curl -L https://nixos.org/nix/install | sh.
                                    Les derivations generees fonctionnent partout ou Nix est installe.
                                

                            


                            

                                
 Pourquoi utiliser Nix pour des binaires precompiles ?

                                

                                    Nix garantit que l'application aura toujours les bonnes bibliotheques,
                                    meme apres les mises a jour systeme. Pas de conflits de dependances,
                                    pas de dependency hell. Chaque application est isolee dans son
                                    propre environnement.
                                

                            


                            

                                
 Comment mettre a jour un paquet installe ?

                                

                                    Remplacez le fichier source dans ~/nix-packages/<nom>/
                                    et reexecutez nix-env -i -f default.nix.
                                    Nix cree une nouvelle generation et bascule automatiquement dessus.
                                

                            


                            

                                
 Comment desinstaller ?

                                

                                    nix-env -e <nom-du-paquet>
                                    Vous pouvez aussi revenir a une generation precedente avec
                                    nix-env --rollback.
                                

                            


                            

                                
 Les formats .deb et .rpm fonctionnent-ils sans dpkg/rpm ?

                                

                                    Oui. app2nix integre dpkg dans sa derivation Nix via
                                    nativeBuildInputs. Lors de la construction,
                                    Nix telecharge et utilise dpkg dans un environnement
                                    isole. Aucune installation systeme requise.
                                

                            

                        


                        
                        

                            

                                
 "unfree license" refuse

                                

                                    Ajoutez NIXPKGS_ALLOW_UNFREE=1 devant la commande
                                    d'installation :
                                    NIXPKGS_ALLOW_UNFREE=1 nix-env -i -f default.nix.
                                    app2nix inclut deja cette variable dans les scripts generes.
                                

                            


                            

                                
 "unsupported system" refuse

                                

                                    Ajoutez NIXPKGS_ALLOW_UNSUPPORTED_SYSTEM=1 (ou les deux
                                    variables combinees). app2nix gere automatiquement ce cas dans
                                    les scripts generes et le bouton "Copy Install Command".
                                

                            


                            

                                
 Le serveur ne repond pas

                                

                                    Verifiez que le conteneur Docker est en cours d'execution :
                                    docker ps | grep app2nix.
                                    Consultez les logs : docker logs app2nix.
                                    L'API doit etre accessible sur http://localhost:8000/api.
                                

                            


                            

                                
 "400 Bad Request" au telechargement

                                

                                    Verifiez que le format du fichier est supporte (.deb, .rpm, .AppImage,
                                    .tar.gz, .tgz, .flatpak, .snap). L'extension du fichier doit
                                    correspondre exactement a un des formats supportes.
                                

                            


                            

                                
 La conversion echoue avec "builder failed"

                                

                                    Verifiez que le fichier source (.deb, .AppImage, etc.) se trouve
                                    dans le meme repertoire que default.nix.
                                    Les chemins relatifs dans la derivation Nix pointent vers
                                    le repertoire source ($src).
                                

                            


                            

                                
 Astuce : Installation rapide

                                

                                    Utilisez le bouton "Copy Install Command" dans l'onglet
                                    de resultat. Il copie une commande unique qui cree le repertoire,
                                    ecrit default.nix et lance l'installation.
                                

                            


                            

                                
 Astuce : Script autonome

                                

                                    Utilisez le bouton "Download Install Script"
                                    pour telecharger un script shell complet qui automatise
                                    toute l'installation du paquet converti.
