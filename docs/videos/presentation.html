Vidéo de Support - Installation et Utilisation

Qu'est-ce qu'app2nix ?

  • ✓ Analyser les packages Linux
  • ✓ Détecter les dépendances
  • ✓ Générer les expressions Nix
  • ✓ Installer sur NixOS
Formats Supportés
  • .deb (Debian/Ubuntu)
  • .rpm (RedHat/Fedora)
  • .AppImage
  • Flatpak

Installation en 3 étapes

Étape Commande Temps
1. Installation curl -sL ... | bash 2 min
2. Avec Docker curl ... | bash -s -- --docker 3 min
3. Vérification app2nix --version 10 sec
